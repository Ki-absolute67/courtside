Courtside v1.1.0

把 Courtside 装进你的 Chrome

Courtside 是一个 Chrome 浏览器插件。点一下工具栏上的篮球图标，就能看到 NBA 实时比分、排名、你关注的球队和数据榜。安装大约两分钟，不用注册，也不花钱。

适用于 电脑上的 Chrome / Edge 需要 联网 数据来自 ESPN

安装步骤

  1. 解压压缩包

    双击收到的 Courtside-v1.1.0.zip，会得到一个叫 Courtside 的文件夹和这份说明。

    把 Courtside 文件夹放到一个不会被误删的地方，比如「文稿 / Documents」。

    装好以后不要删除或移动这个文件夹。Chrome 每次都是从这里读取插件的，文件夹没了插件就打不开了。

  2. 打开扩展程序页面

    在 Chrome 地址栏粘贴下面这串地址，按回车：

    chrome://extensions

    用 Edge 浏览器的话，地址是 edge://extensions。这类地址点链接打不开，只能粘贴到地址栏。

  3. 打开「开发者模式」

    在页面右上角找到这个开关，把它打开：

    开发者模式Developer mode

    打开后，页面左上角会多出几个按钮。

  4. 加载插件

    点左上角的这个按钮：

    加载已解压的扩展程序Load unpacked

    在弹出的窗口里，选中第 1 步的 Courtside 文件夹，点「选择」。列表里出现 Courtside NBA Stats 的卡片，就说明装好了。

  5. 固定到工具栏

    点 Chrome 右上角的 拼图图标，找到 Courtside，点旁边的 图钉：

    🧩→Courtside NBA Stats📌

    之后工具栏上会一直显示橙色篮球图标，点一下就能打开。

  6. 选择你的球队

    打开插件，点顶部的 My Team，选你关注的一支或几支球队，点 Done。以后想改，点 Edit teams 就行。

能看什么

Scores比分

每天的比赛和实时比分。点进一场比赛，能看两队数据对比、场上五人站位和替补名单。

Standings排名

常规赛排名，还有 NBA Cup 小组赛和淘汰赛，以及季后赛对阵图（可以看全部，也可以只看东部或西部）。

My Team我的球队

你关注的球队：最近和接下来的比赛、按月份的赛程、全队球员数据和主教练。

Leaders数据榜

得分、篮板、助攻等各项数据的联盟排名，点表头可以换排序。

你的球队在比赛时，工具栏图标上会出现球队缩写（比如 LAL）。打开一次插件，提醒就会消失。

收到新版本时怎么更新

  1. 解压新的压缩包，用里面的文件替换你原来 Courtside 文件夹里的文件。
  2. 打开 chrome://extensions，点 Courtside 卡片上的 刷新 ↻ 按钮。

插件底部会显示版本号，比如 v1.1.0，可以用来确认更新成功了。

常见问题

Chrome 提示「请停用开发者模式下的扩展程序」怎么办？

点「保留」或者直接关掉提示就行。自己安装的插件都会有这个提示，不影响使用。

加载时提示「清单文件缺失或不可读」？

说明选错了文件夹。要选的是直接装着 manifest.json 的那个文件夹。有时解压后会多套一层同名文件夹，点进去一层再选就好。

打开后一直显示加载失败？

检查一下网络。插件的数据都是打开时从 ESPN 实时获取的，没网就加载不出来。

手机上能用吗？

插件只能装在电脑的 Chrome 或 Edge 上。手机可以打开网页版：profound-biscochitos-40ea6b.netlify.app（网页版功能比插件少一些）。

安全吗？会收集我的信息吗？

不会。插件只读取 ESPN 公开的 NBA 数据，不需要账号，也不收集任何个人信息。它只申请了三项权限：访问 ESPN 的数据、定时刷新比分（用来更新图标提醒），以及保存你选的球队。

怎么卸载？

打开 chrome://extensions，在 Courtside 的卡片上点「移除 / Remove」，然后删掉 Courtside 文件夹就行。
